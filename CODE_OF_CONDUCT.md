# Code Of Conduct

## Our Standard

Kimicode should feel like a calm, serious, helpful place to build. Be respectful, direct, and collaborative. Critique code and ideas, not people.

Examples of behavior that help:

- giving concrete technical feedback
- explaining tradeoffs clearly
- assuming good intent while staying honest about problems
- sharing reproduction steps, logs, and failing cases without blame

Examples of behavior that are not acceptable:

- harassment, intimidation, or personal attacks
- posting someone else's secrets, private data, or credentials
- abusive language aimed at contributors or maintainers
- derailing technical discussions with hostility

## Enforcement

Project maintainers may remove comments, close threads, or block contributors whose behavior makes the project unsafe or unproductive.

## Reporting

If someone crosses the line, contact the repository owner privately rather than escalating the situation in public threads.
